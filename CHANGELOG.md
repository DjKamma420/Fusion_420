## [Unreleased]

### Added

- Profit overlay next to the Fusion Machine GUI with costs, revenue, profit, and return.
- Up to six fusion results.
- Independent buy and sell price modes.
- Self-Farmed buy mode with zero input cost.
- Chameleon Shard support with dynamic output IDs.
- Input-shard highlighting when hovering a fusion result.
- Draggable overlay with saved position.
- Overlay rendered behind Minecraft item tooltips.
- Bazaar price retrieval through the public keyless Hypixel API, with caching and manual refresh.
- Recipe data sourced from [SkyShards](https://github.com/Campionnn/SkyShards), refreshed automatically and cached locally.
- Warning when visible shards are missing from the current recipe data.
- Recipe-data source indicator: online, cache, or bundled.
- Optional release-version check on startup.
- English documentation, security policy, contribution guide, issue templates, Dependabot configuration, and editor configuration.
